*O atlas de constelacións da galería: dous campos no JSON (`icon: "logic-…"`, `preset: "neon"`) e un comando (`ygg layout`) — ningún píxel tocado á man.*

```bash
pnpm add @yggdrasil-forge/core @yggdrasil-forge/react   # renderer
pnpm add -D @yggdrasil-forge/cli                        # ygg (a vía do dato)
```
